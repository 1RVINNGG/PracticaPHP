# Práctica PHP

Repositorio con ejercicios prácticos del curso de Desarrollo Web, sobre introducción al lenguaje PHP.

## Contenido

- `iniciacion.php` — Ejercicio de iniciación (Hello World)
- `verificacion.php` — Verificación de instalación con phpinfo()
- `enbebido1.php` — Ejemplo de PHP embebido en HTML
- `operaciones.php` — Operaciones matemáticas (suma, resta, multiplicación, división, módulo, potenciación, redondeo, valor absoluto)
- `variables.php` — Uso de variables en PHP
- `formulario.php` / `pagina2.php` — Formulario HTML con $_REQUEST (nombre y edad)
- `laboratorio1p.php` / `resultado1.php` — Conversión de pulgadas a centímetros
- `laboratorio1.php` / `resultado_circulo.php` — Área y perímetro de una circunferencia
- `problema2.php` / `resultado_calculadora.php` — Calculadora básica

## Tecnología utilizada
PHP, WampServer (Apache y MySQL), HTML, CSS, Visual Studio Code, Git y GitHub
